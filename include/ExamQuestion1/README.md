Priority Queue:
In this project, I implemented a priority queue in C++ using a doubly linked list. 
Items with higher priorities are removed first.
I used the List<T> class to store items and the PriorityQueue<T> class to manage priorities. 
I implemented push(), top(), and pop(). Items with equal priorities follow FIFO order.
push(): O(n) worst case
top(): O(1)
pop(): O(1)
Through this project, I learned how to use linked lists, templates, and exception handling in C++. 
My priority queue works correctly, but a binary heap would be more efficient for large amounts of data.
