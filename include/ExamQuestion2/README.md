Vector Implementation in C++:
In this project, I implemented a custom Vector class in C++ using a dynamic array. 
I also created iterators to access and modify elements.
I implemented functions such as push_back(), size(), empty(), and operator[]. 
I also added iterator and const_iterator to support traversing the vector.
I created VectorSTLCopy to use std::copy() and VectorBigStep to increase capacity by four times when more space is needed.
I tested iterator traversal, element modification, empty vectors, const iteration, and the -> operator. 
I also tested how the vector grows when new elements are added.
Through this project, I learned how to manage dynamic memory, implement iterators, and use inheritance in C++. 
I also learned how different capacity growth strategies affect a vector's memory allocation.
